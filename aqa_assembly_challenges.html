Labels

        
A label is placed in the code by writing an identifier followed by a colon (:). To refer to a label, place the label identifier after the branch instruction.

        
Comments

        
A semicolon (;) starts a comment, either on its own line or after an instruction or label. Everything after it on that line is ignored, for example ADD R3, R3, #1 ; add one to the count.

        
Interpretation of <operand2>

        
    
          
  • # — use the decimal value specified after the # (for example, #25 means decimal value 25).
    • 
          
  • Rm — use the value stored in register m (for example, R6 means use the value stored in register 6).
    • 
        

        
The available general purpose registers that the programmer can use are numbered 0 to 12.

        

          
Extended mode

          
Extended mode is not part of the AQA specification. It adds the features real assembly programs need for input, output, data and subroutines. Every AQA instruction above still works.

          

          
Extra forms of <operand2>

          
    
            
  • #'A' — the character code of a single character (here 65).
    • 
          

          
Extra forms of <memory ref>

          
    
            
  • 150 — direct: any address 0..1023.
    • 
            
  • total — direct, using a label defined in the .data section.
    • 
            
  • [R2] — indirect: the address is the value in R2.
    • 
            
  • [R2, #3] — indexed: the address is R2 + 3.
    • 
            
  • [R2, R3] — indexed: the address is R2 + R3 (useful for arrays).
    • 
          

          
The .data section

          
Put .data on its own unindented line, then labels on their own lines followed by indented directives. Put .text before the instructions. Data is placed in memory from address 200 upwards.

          
    
            
  • .word 5, -2, 'A' — one memory word per value.
    • 
            
  • .space 20 — reserve 20 words set to 0.
    • 
            
  • .asciz "HELLO" — one character code per word, followed by a 0 terminator.
    • 
          

          
Memory map

          
    
            
  • 0–99 free; 100–199 challenge data; 200+ the .data section.
    • 
            
  • The stack grows downwards from 767. SP starts at 768 (empty stack).
    • 
            
  • 768–1023 the screen: pixel (x, y) is at address 768 + y×16 + x. Storing a colour number there lights the pixel; loading reads it back.
